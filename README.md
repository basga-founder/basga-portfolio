# Portfolio Vue 3

## Menjalankan
1. `npm install`
2. `npm run dev`

Untuk produksi: `npm run build`, lalu `npm run preview` untuk memeriksa hasil build.

## Personalisasi
Ubah semua informasi di `src/data/portfolio.js`: nama/kontak pada `profile`, daftar kemampuan pada `skills`, serta proyek pada `projects`. Foto placeholder memakai URL `pravatar`; ganti properti `image` dengan berkas/URL foto Anda sendiri.
